# OpC_12_ZenAssist — Joseph Truffinet

Projet OpenClassrooms 12 : comparaison d'algorithmes de classification et intégration dans une plateforme de gestion des réclamations. Démarrage : octobre 2026.

- **Mission 1 — exploration :** [notebook unique, sources et résultats](exploration/README.md), dont comparaison de quatre LLM et de plusieurs algorithmes ML.
- **Mission 2 — LLM :** [application JavaScript/Next.js](javascript/README.md), sur la branche `main`.
- **Mission 3 — ML :** [application et API Python/FastAPI](https://github.com/Jojostimabl/OpC_12_ZenAssist/tree/mission-3-ml), sur la branche `mission-3-ml`, avec export du modèle et workflow de release.

Le dossier `typescript/` est le starter officiel conservé en référence ; les intégrations sont réalisées dans la variante JavaScript. Les README de chaque mission décrivent installation, configuration et tests.

Le support de présentation est livré séparément et reste en cours de mise à jour. Les clés privées, environnements, dépendances installées, bases locales et CSV source ne sont pas publiés.
